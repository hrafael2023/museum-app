# Museum App

Projeto Museum App. Publicado no GitHub Pages:
https://hrafael2023.github.io/museum-app/

## Como ver localmente

Abra o `index.html` no navegador, ou rode um servidor simples na pasta:

```bash
python3 -m http.server 8000
```

e acesse http://localhost:8000.

## Versão

A versão atual fica no arquivo `VERSAO` e aparece no rodapé da página.
